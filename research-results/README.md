# Experiment results

Kimi and DeepSeek results, validation checks, configuration, analysis and extracted reasoning responses. The original Amogh source commit and model configuration are recorded in each manifest. Kimi pilot and study reasoning traces are compressed JSONL, keyed by API attempt.

Original raw requests and SSE streams, container inputs, archived source copies, and unrelated prototype output remain in the local ignored `results/` directory. Those bulky raw request files are not included in this public repository; they require separate review and storage. The pilot X condition uses a smaller trace pool than the full study; do not pool them without qualification.
